The charges

A rap sheet, not a vibe check.

Every count below is tied to a source, preferably Microsoft's own words. Claims we could not source were dropped. This is an opinion site, but the exhibits are real.

01

The Start menu sells you things.

Microsoft ships "recommendations" in the Windows 11 Start menu, including Microsoft Store apps. The company's own support pages describe personalized tips, ads, and recommendations, and they give you a toggle after the ads have already found a home on your desktop. You can turn them off. You should not have had to.

The Verge, Apr 2024 Microsoft Support: Recommendations & offers
02

A Microsoft account is required just to finish setup.

Microsoft's own Windows 11 specifications say Windows 11 Home and Windows 11 Pro for personal use "require internet connectivity and a Microsoft account during initial device setup." In October 2025, a Windows Insider blog post said the company was "removing known mechanisms for creating a local account in the Windows Setup experience (OOBE)." You can still wrangle a local account later. Getting to the desktop now starts with a sign-in they decided is non-negotiable.

Windows 11 specifications Windows Insider blog, Oct 6, 2025
03

Recall was built to snapshot what you see.

Microsoft describes Recall as a feature that "periodically takes a snapshot of what appears on your screen" so you can search what you have already seen, "operating like your own virtual and completely private photographic memory." After security researchers and users pushed back, Microsoft delayed the launch, said the feature would be off unless you opt in, and later described snapshots as stored and processed locally, not sent to Microsoft. Those are real improvements. They do not change the original idea: an operating system vendor built a timeline of your screen.

Windows Experience Blog, Jun 7, 2024 Microsoft Support: Recall privacy
04

Updates install themselves. Then the PC wants a restart.

Microsoft's support page on active hours is refreshingly honest: "The great news is that you don't have to do anything to get the latest updates, as they'll automatically download and install when they're available." Then: "Occasionally, your PC might need to restart to finish installing the updates." Active hours try to dodge the worst moment. They do not give you a real off switch. The machine will get there when it wants to.

Microsoft Support: active hours
05

Required diagnostic data has no off switch on Home or Pro.

Microsoft splits diagnostic data into Required and Optional. Required data is "the minimum level of diagnostic data needed to help keep your device reliable, secure, and operating normally," and it is transmitted to Microsoft. Official policy docs describe a "Diagnostic data off" value, then immediately limit it: that value "is only supported on Enterprise, Education, and Server editions." On other editions, setting it to off is "equivalent to setting the value of 1." You can refuse the optional pile. The required pile still leaves the building.

Microsoft Support: diagnostics Microsoft Learn: AllowTelemetry
06

A "clean" install still arrives with junk.

Windows 11 still stages preinstalled apps and promotional Start tiles. How-To Geek documents how Microsoft and PC makers inject shortcuts, trial software, and cloud-fetched placeholders, and how some of that can return if you only remove it from your user profile. You can uninstall a lot of it. Spending your first evening evicting software you never asked for is a wild definition of a personal computer.

How-To Geek, Oct 13, 2026
07

TPM 2.0 and a short CPU list retire working machines.

Microsoft's Windows 11 specifications require a compatible 64-bit processor, UEFI with Secure Boot capability, and TPM 2.0. If a device does not meet those requirements, Microsoft says you "may not be able to install Windows 11 on your device and might want to consider purchasing a new PC." In late 2023, Canalys estimated about 240 million PCs could not officially upgrade, as reported by Tom's Hardware. That estimate is not a landfill count. It is a measure of how many working machines Microsoft's own cutoff left behind.

Windows 11 specifications Tom's Hardware on Canalys, Dec 2023
08

Windows 10 support ended October 14, 2025.

Microsoft's own support page says that on that date it stopped providing technical assistance, feature updates, and security updates for Windows 10. The PC still boots. It just no longer gets official security fixes. If a machine cannot move to Windows 11, Microsoft's guidance includes the paid Extended Security Updates program, or replacing the device. The deadline was not a surprise. The hardware gate in charge 07 is what turned a routine sunset into a shove.

Microsoft Support: Windows 10 end of support

Fresh install to a working desktop

From boot media to a session you can actually use.

Windows

Home and Pro for personal use require internet and a Microsoft account during setup. Microsoft's OOBE list still includes privacy screens, a OneDrive pitch, a Microsoft 365 trial, and OEM registration pages. That is a lot of hallway between "hello" and a desktop.

Annoyance
Win11 specs Microsoft Learn: OOBE

macOS

Setup is cleaner, and you can skip signing in with an Apple ID. The machine itself is the tax: a new Mac mini starts at $899 on Apple's own store. You paid luxury-computer money, and you still have to sit through the tour.

Annoyance
Apple: Mac mini, from $899

Omarchy

Write the official ISO to a USB stick, turn off Secure Boot and/or TPM in the BIOS, answer a short set of configuration questions, and pick a drive. Full-disk install wipes that drive, and encryption is on by default. The manual says it can be done in under a minute on the fastest modern machines, and should not take more than 5 minutes even on an older computer. That BIOS step is real work. It is still less of a gauntlet than an MSA sign-in plus a software trial.

Open a terminal

How fast can you get a prompt that feels first-class?

Windows

Windows Terminal exists now, and you can find it from search or Win+X. That is progress. A prompt still is not the center of the desktop. For years the "real" path was Win+R, then cmd, then an argument with IT.

Annoyance

macOS

Terminal lives in Utilities. Spotlight will find it. It works, it is not hidden, and it is also not celebrated. Fine. A little dusty.

Annoyance

Omarchy

Press Super + Return. Foot is the default terminal. The binding follows whichever terminal you pick later under Install, so the muscle memory stays put. The keyboard is the point of the desktop, not a side door.

Install an app

Getting software onto the machine without a lecture.

Windows

The Microsoft Store, a downloaded installer, SmartScreen, maybe a reboot. winget exists if you already know to look for it. The default path still feels like a permission slip.

Annoyance

macOS

The App Store is easy. Outside it, Apple's default Gatekeeper rules expect a Developer ID signature and notarization before an app opens without a fight. That is not an iPhone-style lock, but Apple still stands between you and an unsigned binary. It is a garden with a side gate, and the gate has a clerk.

Annoyance
Apple: safely open apps Apple: notarization

Omarchy

Super + Space opens the Omarchy menu. Install lives there, including terminals, editors, and dev stacks. No storefront ads, no notarization clerk. The tradeoff is the usual Linux one: you should be willing to read a package name.

Change the theme

Can the whole machine change its mind at once?

Windows

Light, dark, a handful of accent colors, a wallpaper. A real system-wide theme still means third-party tools and a hope that the next feature update will not reshuffle Settings. Meanwhile the Start menu may still be trying to recommend you an app.

Annoyance

macOS

Light, dark, accent color, wallpaper. It looks considered. It does not restyle your terminal, your editor, and your system chrome as one piece. And when a new macOS ships, the upgrade nags can be persistent enough that people publish profiles just to quiet them.

Annoyance
Daring Fireball: Tahoe alerts

Omarchy

Super + Ctrl + T opens the theme selector. Omarchy ships twenty-two themes. Each one styles the desktop, terminal, Neovim, btop, Chromium, and the whole Omarchy shell: top bar, menu, notifications, OSD, and lock screen. One decision, the entire machine follows.
